Architecture & Methodology

TruthLens pairs traditional machine learning with modern neural embeddings and a rule-based credibility arbitration layer to evaluate veracity transparently.

01

NLP Normalization & Sensationalism Token Retention

preprocess.py

Standard stopword filters remove words indiscriminately. TruthLens applies WordNet lemmatization, URL/HTML tag stripping, and consecutive duplication removal, but explicitly preserves high-signal sensationalist triggers (e.g., shocking, bombshell, coverup, leaked, conspiracy, suppressed) as critical contextual indicators.

Input Text → Lowercase & Regex Clean → WordNet Lemmatization → Handcrafted Stylometry Extraction
02

Dual Feature Stacking: TF-IDF + Stylometry Ensemble

predict.py

Lexical TF-IDF vectors are horizontally stacked with scaled handcrafted stylistic features (uppercase shouting ratio, exclamation count, question density, quote usage, average word length, and sentence count). The stacked feature matrix is classified by an scikit-learn VotingClassifier to yield baseline class probabilities.

Sparse TF-IDF Matrix (50,000 vocab) ⊕ Scaled Stylometric Vector → VotingClassifier(SVM + LR)
03

Rule-Based Credibility & Uncertainty Arbitration

decision_engine.py

Statistical models can misclassify preliminary scientific articles as false, or trust sophisticated conspiracy propaganda. The decision engine evaluates 3 phrase registries: strong fake triggers, institutional authority citations, and 3 tiers of scientific hedging language. It applies priority overrides and arbitrates probability gaps to flag genuine uncertainty.

Fake Score vs. Real Score → Net Credibility Score ⊕ Tiered Uncertainty Index → Arbitration Override
04

Transformer Context Embeddings & Safe Cloud Fallback

bert_predict.py

When connected to the Hugging Face inference router, fine-tuned transformer weights (Monk3ydluffy/truthlens-bert) evaluate semantic nuance with a non-blocking timeout wrapper. If cloud inference is unavailable or times out, the local ensemble and decision engine take over seamlessly without service interruption.

Hugging Face Router API → 20s Thread Timeout → Blended Decision or Automatic SVM Fallback

Frequently Asked Technical Questions

Does TruthLens fact-check live events in real time?

No. TruthLens is a linguistic and stylistic analysis tool. It analyzes the style, framing, tone, and attribution structure of text based on historical patterns of verified and debunked reporting. It does not browse the live web or verify unrecorded events in real time.

Why does the system classify some text as "UNCERTAIN"?

Responsible news reporting frequently includes hedged language when covering preliminary clinical trials, active investigations, or scientific debates. Binary real/fake classifiers often penalize cautious phrasing. TruthLens detects hedging vocabulary and marks such content as UNCERTAIN to reflect the nature of the claim.

What training data was used for the local models?

The models were trained on balanced sets of over 44,000 real and fake news articles, incorporating political news, scientific reporting, press announcements, and debunked misinformation archives.
